Projetos

  • Machine learning aplicado ao monitoramento agrícola: estudo de caso no cultivo de milho em Luís Eduardo Magalhães (BA)

    O TCC buscou verificar quais dos 9 modelos de machine learning foram mais representativos em relação ao mapeamento manual de culturas agrícolas. A ideia foi executar os modelos sem processamento de ruído ou validação manual, comprovando a acurácia de cada um e identificando qual exigiria menos retrabalho na revisão.

  • RTH PROJECT — Plugin QGIS para Mapeamento Agrícola & ESG

    Plugin open-source para QGIS que centraliza ferramentas de sensoriamento remoto e mapeamento agrícola em um único ambiente. Do catálogo de imagens via STAC ao planejador de voo para drones, cada ferramenta foi desenvolvida para otimizar o fluxo de trabalho do profissional de geotecnologias no agronegócio.

  • Catálogo de Culturas

    Catálogo pessoal de assinaturas espectrais e padrões visuais de culturas agrícolas — uma espécie de Pokédex do agro. Reúne composições de bandas, índices de vegetação e comportamento temporal de cada cultura, servindo como referência rápida para identificação em imagens de satélite.

  • RTH World Explorer — Aplicativo de Celular do Campo ao Escritório

    Aplicativo Android desenvolvido para o profissional que trabalha do campo ao escritório. Captura pontos georreferenciados de culturas com fotos, coleta parâmetros produtivos (soja, milho, algodão, arroz e outros) e gera grids amostrais de agricultura de precisão — totalmente integrado ao plugin RTH PROJECT para QGIS.

  • RTH Análise de Polígono

    O projeto recebe um polígono específico em JSON junto com um intervalo de tempo, gerando thumbnails em três composições de bandas — RGB, NIR-SWIR-RED e NIR-SWIR-RED contrastada — que podem ser clicadas para melhor visualização no mapa central.

  • RTH Gráficos de Vegetação

    O projeto recebe uma coordenada de latitude e longitude e plota gráficos de índices de vegetação relevantes para o mapeamento agrícola, permitindo uma melhor diferenciação entre culturas sem depender de sites externos.

  • RTH Visualizador de Clima

    O projeto plota variáveis climáticas importantes para estados brasileiros ou para o Brasil, incluindo um modelo de previsão do tempo, eliminando a dependência de sites externos para análises agrícolas.

  • RTH Verificar Desmatamento

    O projeto recebe um polígono específico em JSON junto com a seleção dos anos e meses de interesse, gerando thumbnails que facilitam a visualização e a análise do desmatamento nos períodos selecionados.

  • Problema monitor agrícola John Deere

    Este monitor não transferia os dados para o pendrive, causando a perda dos registros de produção por tratamento. Com o pacote pliman foi possível catalogar a cor de cada pixel e medir as produtividades, resolvendo o problema de perda de dados.

  • Extração de Dados de PDF

    O projeto resolveu o problema de extrair dados de PDFs do CEASA de SC, obtendo as cotações de verduras e frutas em formato de tabela estruturada. Com isso foi possível criar um banco de dados robusto e atualizado automaticamente.

  • Extrair Chuva INMET

    O projeto automatizou o download de dados de precipitação do site do INMET utilizando Selenium, reduzindo significativamente o tempo gasto na coleta dessas informações.

  • TimeLapse utilizando Latitude e Longitude

    O projeto recebe uma latitude, longitude e um intervalo de tempo, gerando um GIF do local em diferentes composições de bandas (RGB, NIR-SWIR-RED etc.), facilitando a criação de materiais didáticos.

  • Extrair dados da ABRAPA

    O projeto recebe um arquivo Excel com empresas que beneficiam algodão, busca cada empresa no Google e extrai sua latitude e longitude, criando um banco de dados geolocalizado de unidades beneficiadoras de algodão.

  • Contagem de elementos

    O projeto resolveu o problema de contar manualmente os elementos em placas de Petri ou grãos de soja, automatizando o processo por meio de análise de imagem a partir de uma fotografia.
