RTH World Explorer

Política de Privacidade

Última atualização: novembro de 2026

Idioma

O RTH World Explorer é um aplicativo mobile de código aberto e sem fins lucrativos, desenvolvido de forma independente para coleta de pontos geográficos e parâmetros produtivos em campo. Esta Política de Privacidade descreve quais informações são coletadas pelo aplicativo, de que forma são utilizadas, como são armazenadas e quais são os direitos do titular em relação a esses dados. Ao utilizar o aplicativo, o usuário declara estar ciente e de acordo com os termos aqui descritos.

1. Dados Coletados

  • Localização GPS (latitude, longitude e direção) — coletada exclusivamente quando o usuário aciona a captura de coordenada
  • Imagens capturadas pela câmera do dispositivo para registro de pontos de coleta e comprovantes de despesas
  • Dados inseridos pelo usuário em formulários: nome do responsável, rota, cultura, observações e parâmetros produtivos
  • Preferências do aplicativo: idioma, tema visual e rascunhos de formulários salvos localmente
  • Dados de uso do aplicativo — somente mediante consentimento explícito do usuário nas configurações

2. Base Legal para o Tratamento (Art. 7 — LGPD)

Todo tratamento de dados realizado pelo RTH World Explorer possui fundamento legal expresso na Lei Geral de Proteção de Dados (Lei nº 13.709/2018):

Dado Base Legal
Localização GPS Consentimento do titular (Art. 7, I) — acionado pelo próprio usuário
Imagens da câmera Consentimento do titular (Art. 7, I) — acionado pelo próprio usuário
Dados de formulário Execução de contrato / legítimo interesse (Art. 7, II e IX) — necessários para o funcionamento do app
Preferências locais Legítimo interesse (Art. 7, IX) — melhoria da experiência do usuário
Dados de uso (opcional) Consentimento explícito do titular (Art. 7, I) — opt-in nas configurações do app

3. Uso dos Dados

  • Todos os dados são armazenados localmente no dispositivo do usuário
  • Nenhum dado é transmitido automaticamente para servidores externos
  • O usuário pode exportar os dados nos formatos CSV, Excel ou por compartilhamento nativo do sistema operacional
  • O aplicativo não utiliza conta de usuário, autenticação social nem perfil online

4. Permissões Solicitadas

  • Localização: para capturar as coordenadas GPS dos pontos registrados em campo
  • Câmera: para registrar imagens associadas aos pontos de coleta e comprovantes
  • Armazenamento: para salvar imagens e exportar arquivos CSV/Excel no dispositivo
  • Internet: para carregar os tiles do mapa (OpenStreetMap) quando há conexão disponível
  • Notificações: para informar o progresso de exportações realizadas em segundo plano

5. Compartilhamento de Dados

O RTH World Explorer não compartilha dados com terceiros de forma automática. Os arquivos exportados (CSV, Excel) permanecem sob controle exclusivo do usuário. O aplicativo não transmite informações para servidores de análise de uso (analytics), plataformas de publicidade ou quaisquer serviços externos.

Caso o usuário deseje contribuir com o aprimoramento contínuo do aplicativo, existe a opção de compartilhar dados de uso com o desenvolvedor diretamente pelo menu de configurações. Essa funcionalidade é inteiramente opcional, depende de consentimento explícito do titular e pode ser revogada a qualquer momento, sem qualquer impacto no funcionamento do aplicativo.

6. Dados de Localização

A localização é capturada de forma pontual (snapshot) somente quando o usuário aciona explicitamente a função de captura de coordenada. O aplicativo não realiza rastreamento contínuo de localização em segundo plano fora das funcionalidades explícitas de mapa e GPS sob demanda.

7. Medidas de Segurança

O RTH World Explorer adota as seguintes medidas para proteger os dados do usuário:

  • Os dados são armazenados em banco de dados local (SQLite) no diretório privado do aplicativo, inacessível a outros apps sem permissão explícita do sistema
  • Imagens são salvas no armazenamento interno privado do aplicativo
  • Nenhuma informação pessoal é transmitida sem ação explícita do usuário (exportação ou compartilhamento opcional)
  • Quando o compartilhamento opcional de dados de uso está ativado, a transmissão ocorre por conexão cifrada (HTTPS/TLS)
Nenhuma medida de segurança é absolutamente infalível. Recomendamos que o usuário mantenha o sistema operacional e o aplicativo sempre atualizados.

8. Retenção e Exclusão de Dados

Os dados ficam armazenados no banco de dados local do dispositivo e nas pastas de armazenamento interno do aplicativo. O usuário pode excluir pontos, imagens e registros individualmente pelo próprio app, ou remover todos os dados desinstalando o aplicativo do dispositivo. Não há retenção de dados em servidores externos após a desinstalação.

9. Direitos do Titular (Art. 18 — LGPD)

O RTH World Explorer não armazena, processa nem transmite qualquer dado que configure tratamento irregular nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018). O aplicativo não possui sistema de contas, cadastro ou autenticação de usuários — todas as informações coletadas permanecem exclusivamente no dispositivo do titular e sob seu controle direto.

A única hipótese de envio de dados ao desenvolvedor ocorre mediante consentimento explícito e voluntário do usuário, ativado nas configurações do aplicativo. Ao exercer essa opção, o usuário realiza uma doação voluntária de dados de uso ao criador do app, com o objetivo de apoiar a produção de artigos técnicos e científicos nas áreas de mapeamento agrícola e sensoriamento remoto. Essa autorização pode ser revogada a qualquer momento, sem qualquer impacto no funcionamento do aplicativo.

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o titular dos dados pessoais possui os seguintes direitos, exercíveis mediante solicitação ao controlador:

Acesso Confirmar a existência de tratamento e obter acesso aos dados pessoais mantidos pelo app.
Correção Solicitar a correção de dados incompletos, inexatos ou desatualizados.
Eliminação Requisitar a exclusão dos dados tratados com base em consentimento.
Portabilidade Solicitar a exportação dos dados em formato interoperável para outro fornecedor.
Revogação Retirar o consentimento a qualquer momento, inclusive o do compartilhamento opcional de dados de uso.
Oposição Opor-se ao tratamento realizado com fundamento em outras bases legais, em caso de descumprimento.
Informação Obter informações sobre entidades públicas e privadas com quem os dados foram compartilhados.
Revisão Solicitar revisão de decisões tomadas exclusivamente com base em tratamento automatizado.

Para exercer qualquer um desses direitos, entre em contato pelo e-mail suporterthproject@gmail.com. Responderemos em até 15 dias úteis.

10. Público-Alvo e Proteção de Menores

O RTH World Explorer é destinado exclusivamente a profissionais e equipes de campo do setor agrícola. O aplicativo não é direcionado a crianças menores de 13 anos (COPPA) ou menores de 18 anos sem supervisão parental (LGPD, Art. 14) e não coleta dados de menores de forma intencional. Caso tal situação seja identificada, os dados serão removidos imediatamente mediante solicitação.

11. Usuários da União Europeia (GDPR)

Para usuários localizados no Espaço Econômico Europeu, esta política é igualmente aplicável em conformidade com o Regulamento Geral de Proteção de Dados (GDPR — Regulamento UE 2016/679). Os direitos descritos na Seção 9 correspondem aos direitos previstos nos Artigos 15 a 22 do GDPR.

Usuários europeus têm ainda o direito de apresentar reclamação perante a autoridade supervisora de proteção de dados do seu país de residência, caso considerem que o tratamento de seus dados viola o GDPR.
